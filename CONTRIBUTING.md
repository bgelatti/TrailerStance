# Contributing

Thanks for your interest in Trailer Stance.

- **Issues are welcome.** Use the bug report or feature request templates. For bugs, attach `BepInEx\LogOutput.log` and, if possible, the F9 dump of the trailer.
- **Pull requests are not accepted.** This is a single-maintainer project and the code is not open source (see [LICENSE](LICENSE)). If you have a fix, describe it in an issue instead.
